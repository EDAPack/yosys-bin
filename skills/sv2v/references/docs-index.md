## Background
- **IEEE 1800-2017 (SystemVerilog)** — for reference when sv2v fails on
  a construct, check whether it's standard SV.
- **IEEE 1364-2005 (Verilog-2005)** — the dialect sv2v *emits*.

## Examples to mirror
- `test/` directory in the sv2v repo: hundreds of small SV → Verilog
  conversion pairs that double as documentation of what's supported.
